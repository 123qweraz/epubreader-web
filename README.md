# EPUB Reader（网页版）

纯本地 EPUB / TXT 阅读器，自同名浏览器扩展移植的独立网页项目。零依赖、零构建、纯静态——所有解析、渲染、存储均在浏览器内完成，**书籍文件不会上传到任何服务器**。

## 功能

- 打开 `.epub` / `.txt`（点击选择或拖入页面），TXT 按章节标题正则自动分卷分章；阅读时工具栏 ✕ 一键关闭回书架
- 书架：最多保留 30 本记录（展示最近 15 本），默认封面网格视图（封面优先取 EPUB 内置封面图，无封面时按书名哈希色相纯色占位；底部细进度条），设置中可切换回列表视图；移除有 5 秒撤销期；阅读进度持久化（IndexedDB），重开同一文件自动续读；「编辑」模式支持多选 / 全选 / 批量移除（同样有 5 秒撤销期）
- 数据备份：书架标题行 ⋯ 菜单中导出/导入 JSON 备份（全部设置 + 阅读进度 + 书目元数据，不含书籍文件本体）；导入的书目为「待关联」状态（书架中带虚线徽章），可点击单本弹选择器恢复，或用「恢复未关联书籍」按钮一次多选文件按大小批量回填，选中同名同大小的原文件后自动续读
- 目录侧栏（可固定/浮动）、全书搜索（含上下文预览与跳转）
- 滚动 / 双列翻页两种排版；字号、行距、页宽、字体调节
- 拼音标注：可开关的汉字上方注音（基于本地 pinyin-pro 词库，多音字按语境识别；注音库首次开启时加载，之后离线可用）。大文档按可视邻域渐进注音——滚动/翻页停稳后只注当前视野附近内容，拖动进度不触发渲染；超长文本自动跳过并提示
- 主题：米白（默认）/ 纯白 / 羊皮纸 / 护眼绿 / 深色五个完整内置主题（外壳与纸面统一配色，留白恒等于界面底色）；自定义主题以「纸面 + 文字」两色起步，界面底色、边框、按钮、强调色等全部随纸面自动联动派生（强调色取微偏补色方向），「更多颜色」展开后可对六项派生结果二次接管微调；支持一键重置本槽
- 中英双语界面，默认跟随浏览器语言，可在设置中切换
- 自动阅读（定时翻章）、书内锚点跳转、外部链接新标签打开

## 本地运行

一键启动（起本地服务并自动打开浏览器）：

```bash
./start.sh          # 默认 http://127.0.0.1:8480/，端口占用自动顺延
./start.sh --app    # Chrome 应用窗口模式(无地址栏)
```

也可用任意静态服务器指向本目录，例如：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

> 不建议直接双击 index.html 以 file:// 打开：部分浏览器对 file:// 来源的 IndexedDB / localStorage 限制较多，书架与进度可能无法保存。

## 部署上线

纯静态站点，任何静态托管开箱即用：

**GitHub Pages**

1. 推送到 GitHub 仓库
2. Settings → Pages → Source 选 `main` 分支 `/ (root)`
3. 访问 `https://<用户名>.github.io/<仓库名>/`

**Cloudflare Pages / Netlify / Vercel**

连接仓库或直接拖拽目录上传，零配置。根目录已含 `.nojekyll`（GitHub Pages 免 Jekyll 处理）。

## PWA（可安装、离线使用）

已内置完整 PWA 支持，部署到 HTTPS 环境后自动生效：

- 浏览器地址栏会出现「安装」按钮（或菜单 → 安装应用 / 添加到主屏幕），安装后以独立窗口运行
- Service Worker 缓存全部应用外壳，首次访问后断网也能正常打开阅读
- 缓存策略：页面导航网络优先（发版即达），静态资源缓存优先 + 后台更新
- File Handling：桌面 / Android Chromium 安装后，可在系统里把 `.epub` / `.txt` 关联到本应用，双击文件或系统分享直接打开（iOS Safari 不支持，自动忽略）
- iOS Safari：分享 → 添加到主屏幕（图标用 apple-touch-icon）

发版注意：改动静态文件后需把 `sw.js` 顶部的 `VERSION` 递增一位（如 `v1` → `v2`），客户端旧缓存才会被淘汰。

## 技术说明

- 解压依赖浏览器原生 `DecompressionStream`（Chrome/Edge 80+、Firefox 113+、Safari 16.4+），需 HTTPS 或 localhost 环境
- 存储：书籍文件与元数据存 IndexedDB（上限 30 本，按最旧读取时间清理）；界面偏好存 localStorage；进度双写（localStorage 热缓存 + IndexedDB 持久）
- 语言检测：`navigator.language`，zh* → 中文、en* → English、其他回退中文；手动选择存 `lang` 键
- 与浏览器扩展版（epubreader 仓库）同源异流：本项目面向 Web 托管独立演化
- 图标：`icons/icon.svg` 为设计源；各尺寸 PNG（192/512/maskable/apple-touch）按该 SVG 几何精确重绘生成
